# web/

The Next.js 16 app (App Router, TypeScript, React Three Fiber, GSAP, Tailwind 4). Setup and the project overview are
in the [repository README](../README.md); environment variables in [`../.env.example`](../.env.example).

```bash
pnpm install
pnpm fetch-hair                # the hair strand files (~220 MB, not in git)
pnpm dev                       # http://localhost:3000
pnpm test && pnpm lint && pnpm typecheck
```

## Where things live

| | |
|---|---|
| `src/components/FaceBuilder.tsx` | the page shell; installs the `window.__faceToVoice` debug handle in development or with `?debug` |
| `src/components/scene/` | the R3F scene: `Head.tsx` (meshes, eye pivots, settle and normals), `IdleLife.tsx`, `LipSync.tsx`, `Lighting.tsx`, `materials.ts`, `Capture.tsx` (the screenshot sent for casting) |
| `src/components/ui/` | the panel (`panel/`), styling controls, the voice card (`VoicePanel.tsx`, `SpeakBar.tsx`), the loader (`loader/`) |
| `src/lib/morphs/` | the morph store (weights → `morphTargetInfluences`, no React renders), the limiter and its worker, Random face, slider travel, Fine-tune reach |
| `src/lib/groom.ts`, `hair.ts`, `addons.ts`, `glassesFit.ts` | strand rendering and the hair and add-on loaders |
| `src/lib/*Shader.ts` | skin, eye and morph shader patches (age wrinkles, stubble, the loader-to-face reveal) |
| `src/lib/lipsync/` | PCM player, letter-to-viseme cues, the evaluator |
| `src/lib/server/` | everything that holds a key: Claude, ElevenLabs, caches, rate limits, guards |
| `src/lib/export/` | Download character: portrait, character code and rebuild link, zip, licence rules |
| `src/data/` | generated by the pipeline: sliders, visemes, limiter, Fine-tune reach, random-face split, age landmarks |
| `src/app/dev/` | tools: the viseme tuner, the hair review, a glb probe; 404 in production |

Tuning lives in named objects at the top of each module: `LIMITS`, `RANDOM`, `MOTION`, `IDLE`, `GROOM`, `ADDONS`,
`GLASSES_FIT`, `SKIN_SHADE`, `EYE_LOOK`, `AGE`, `EMOTION`, `LIPSYNC`, `LIGHTING`, `CHROME`.

## Server routes

| Route | |
|---|---|
| `POST /api/voice/design` | screenshot + slider values + look ids → Claude casting (`claude.ts`, cached per visitor and face) → prompt (`prompt.ts`) → Voice Design previews (cached per description, shared) |
| `POST /api/voice/select` | saves the chosen take as a voice: daily cap, plan quota, LRU pool, studio fallback (`voice.ts`) |
| `POST /api/voice/speak` | `eleven_v4_turbo` stream with timestamps (NDJSON passed through), cached in Blob per voice and line |
| `GET /api/usage` | today's caps, the pool and plan quotas; `Authorization: Bearer $USAGE_ADMIN_TOKEN` |

Every paid route runs `guards.ts` (same-origin, BotID) and `ratelimit.ts` (per-visitor sliding windows and global
daily caps in Upstash Redis; in-memory in development, refused in production without Redis).

## Lip sync

`player.ts` schedules the streamed 24 kHz PCM gaplessly in Web Audio and uses the AudioContext clock as the master
clock; `cues.ts` turns the per-character timestamps into viseme cues (`lipsync-en.ts`, adapted from TalkingHead);
`evaluator.ts` places the line on the voice onset, snaps closures and vowels to the audio, and blends the cues
(anticipation, closure dominance, smoothing); `LipSync.tsx` writes the result into the viseme morph layer every frame.
Presets live in `src/data/visemes.json` and can be tuned by eye on `/dev/visemes`.

Timing knobs are in `LIPSYNC` (`evaluator.ts`). `?lipsync=1` shows the cue timeline; `?lipsyncOffsetMs=` and the Sync
slider in the voice card shift the mouth for audio paths the browser cannot measure (Bluetooth, external displays).

## Scripts

| | |
|---|---|
| `scripts/stress-states.mjs` | the app side of the pipeline's stress test (`uv run validate --stress`) |
